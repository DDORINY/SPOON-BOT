# K4.8 방송 스튜디오 UI

## 화면 구성

`/broadcast`에서 기존 고정 사이드바 + 상단 관측 상태 + 중앙 채팅 + 오른쪽 방송 도우미로 구성한다. `studio.js`는 DOMContentLoaded 이후 기존 DOM을 이동하며 새 API나 자동 연결 요청을 생성하지 않는다. 기존 ID, 폼, CSRF 값, 수동 전송 동의, 조회 버튼과 핸들러를 보존한다. 다른 페이지의 레이아웃은 그대로다.

사이드바 메뉴 링크와 현재 메뉴 강조를 유지하고 내부 스크롤을 허용한다. 모바일은 메뉴 버튼으로 열고 Escape로 닫는다. 키보드 포커스와 aria-expanded/aria-controls를 제공한다.

## 상태와 통계

기존 헤더의 방송/도우미 텍스트를 상태 바와 동기화한다. 방송 조회와 실시간 이벤트 렌더러가 제공한 청취자 및 관측 하트 수량을 사용한다. 방송 상태와 도우미 상태는 별개다. 현재 방송 후원 귀속이 미확정이므로 실제 모드의 현재 방송 스푼/건수는 ‘—’로 유지한다. 최근 저장 기록을 현재 방송 전체 후원으로 표시하지 않는다. 시뮬레이터의 후원 합계와 건수는 ‘가상 저장’ 합계이며 이전 가상 회차가 포함될 수 있다.

## 채팅과 오른쪽 패널

기존 실시간 채팅 카드 안에 기존 수동 입력 카드를 이동한다. 채팅 목록은 내부 스크롤이며 기존 과거 메시지 위치 유지·새 채팅 알림·100건/5분 메모리 정책·UTF-16 검증과 전송 동의를 그대로 사용한다. 입력창은 카드 하단이며 작은 높이에서 입력 섹션도 내부 스크롤을 허용한다.

오른쪽에는 최근 익명 후원 및 하트, 실제 연결/정보 접이식 카드, 시뮬레이터 자동화 요약/설정, 청취자·이번 방송 팬 랭킹을 표시한다. 후원 조회는 기존 세션 검증 API를 기존 helper 폴링과 함께 사용하며 추가 폴링 루프를 만들지 않는다. 기록 조회 거부 시 권한 안내를 유지한다. 실제 자동화는 지원하지 않는다고 명시한다.

## 시뮬레이터

기본 접힌 ‘시뮬레이터 도구’에 기존 제어/결과/가상 시간/자동화 Mock 실행 기록을 옮긴다. 내부 개발 JSON 역시 기본 접힘이다. 기존 시나리오 A–D, 버튼 ID, 설정 적용·중지·초기화·실행 기록을 유지한다. 자동화 상세 폼은 오른쪽의 ‘자동화 설정 열기’로 접어 표시한다. 실제 모드에는 시뮬레이터 패널을 만들지 않는다.

## 스크롤과 반응형

데스크톱 >1100px: 채팅/오른쪽 2열, viewport 기반 높이, 채팅·오른쪽·이벤트·청취자·설정 내부 스크롤.
태블릿 <=1100px: 채팅 우선 한 열, 오른쪽 카드 2열.
모바일 <=760px: 메뉴로 사이드바 개폐, 카드 한 열, 버튼 최소 44px, 입력 폭 제한과 긴 텍스트 줄바꿈.
모든 grid 자식에 min-width/min-height와 overflow를 적용한다. 낮은 높이 및 확대 환경에서는 전체 페이지 스크롤도 허용해 조작부가 잘리지 않게 한다. 과도한 애니메이션을 추가하지 않는다.

## 보존과 검증

OAuth, SSE 파서/연결 정책, 후원 SQLite, 익명화, 수동 채팅, 자동화 엔진·Mock 격리, API 계약을 변경하지 않는다. 세션/CSRF/Origin/Host/CSP를 완화하지 않는다. 실제 API/OAuth/SSE/채팅 호출 및 운영 DB 접근/마이그레이션을 수행하지 않는다.

Python 전체 회귀, Node DOM 레이아웃(실제/가상), 기존 Node 상호작용, JavaScript 문법, pip check, git diff --check로 검증한다. 전체 456개 테스트가 통과했고 JavaScript 문법·pip check·git diff --check도 통과했다. 설치된 Chrome/Playwright/Puppeteer가 없어 실제 화면 크기별 스크린샷이나 가로 스크롤을 검증하지 못했다.

수동 검증: 시뮬레이터로 실행해 1920×1080,1600×900,1366×768,1280×720,1024×768,390×844에서 채팅 입력·과거 메시지 스크롤·새 메시지 알림·오른쪽 접이식 카드·모바일 메뉴·도구 버튼·자동화 상태를 확인한다. 실제 모드는 로그인/API 요청 없이 Mock 테스트로만 회귀 검증했다. 현재 방송 후원 합계 및 계정/회차 귀속 미확정은 기존 한계로 남아 있다.
