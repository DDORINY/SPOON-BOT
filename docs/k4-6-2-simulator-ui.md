# K4.6.2 시뮬레이터 UI 및 상태 통합

실행: `.venv/bin/python -m spoon_local --simulator`
화면: `http://localhost:8000/broadcast`

시뮬레이터 결과 API의 broadcast_state/connection_state를 헤더와 상태 카드의 기준으로 사용한다. 기존 실제 모드 헤더 렌더러는 가상 모드 헤더를 덮어쓰지 않는다. 가상 오류 주입과 로컬 조회 실패는 서로 다른 안내를 표시한다.

방송 화면에서 제어/결과 요약/채팅·하트/청취자·팬/가상 채팅 전송/비활성 미리보기 순으로 기존 카드를 재배치한다. 버튼은 방송, 이벤트, 대량 이벤트, 연결·오류, 시나리오 그룹으로 구분한다. 실행 중 중복 클릭을 막는다. 원문 JSON은 접힌 개발자 상세 영역에서만 표시한다.

결과 변화 시 시뮬레이터 전용 로컬 이벤트로 기존 실시간 조회와 청취자·팬 조회를 갱신한다. 실제 모드의 수동 청취자 조회 정책은 그대로다. 채팅/하트 버퍼와 렌더링 상한도 유지한다. 후원은 기존 메모리 SQLite 저장 경로를 사용하며 요약에서 생성/처리 건수와 스푼 합계를 구분한다. 방송 종료는 현재 버퍼·청취자·팬을 비우고 저장 후원을 보존한다. 초기화는 가상 메모리 기록만 초기화한다.

실제 계정, 운영 DB, .env를 사용하지 않는다. 기존 로컬 세션/CSRF/Host/Origin/CSP 및 외부 네트워크 차단을 유지한다. ‘닫기’ 요소는 프로젝트 소스에서 확인되지 않았으므로 임의 숨김을 추가하지 않았다. Chrome의 실제 DOM 및 확장 기능 여부는 수동 확인이 필요하다.
