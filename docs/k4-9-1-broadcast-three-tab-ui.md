# K4.9.1 방송 화면 3탭

## 화면과 DOM

중앙 실시간 채팅 + 오른쪽 봇 자동화/후원 랭킹/실시간 청취자 탭으로 전환한다. 기본은 봇 자동화다. 한 번 마운트한 기존 요소를 이동하며 선택되지 않은 패널은 hidden 처리한다. 탭 선택은 설정 저장/실행 상태를 초기화하지 않는다. ARIA tablist/tab/tabpanel, roving tabindex, 좌우/Home/End 키를 제공한다.

기존 sidebar·상태 바·입력 동의·채팅 역할/스크롤/100건·5분 정책을 유지한다. 기존 후원 상세/연결/하트 자료는 보조 상세로 보존한다. 실시간 채팅 위에 남던 단독 구분점은 index.html 두 관리 링크 사이의 ‘·’ 텍스트다. 링크가 상세로 이동한 후 남는 텍스트를 제거했다.

## 자동화

기존 감사/안내 체크박스 라벨을 기본 탭으로 옮긴다. 변경하면 저장 설정을 기반으로 해당 플래그만 바꿔 기존 versioned SQLite API로 저장한다. 성공 시 실행은 중지하고 새 확인을 요구한다. 실패는 이전 저장값 복원, 409는 최신 저장값/버전을 재조회해 충돌 안내를 제공한다. 설정 ON은 실행을 의미하지 않는다. 전체 중지와 방송별 명시적 확인은 그대로다.

템플릿·미리보기·간격·저장 폼 및 Mock 기록은 native dialog로 이동한다. 실제 모드는 자동화 사용 불가 안내만 있고 조작/자동 전송 경로를 추가하지 않는다.

## 후원 랭킹과 청취자

[공식 팬 랭킹](https://developers.spooncast.net/docs/api-reference/fans)은 현재 방 청취자 중 이번 방송 누적 후원 상위 30명이다. 퇴장자는 제외되며 전체 방송 후원자/전체 기간 팬 순위가 아니다. 기존 fans.read API와 rank/nickname/spoon_count를 재사용한다. null 후원량은 미확인이다. 기본 상위 5명, 나머지 조회 결과는 모달이다. 익명 후원 DB는 랭킹 생성에 사용하지 않는다.

[공식 청취자](https://developers.spooncast.net/docs/api-reference/listeners)는 현재 방송의 커서 페이지 목록이다. 기본 8명을 보여주고 이번 응답 인원과 표시 인원을 명시한다. 현재 전체 청취자 수는 기존 방송 조회 상태 바에 있으며 목록 수와 혼동하지 않는다. 다음 페이지/수동 갱신·마지막 조회·오류 안내를 유지한다. 전체 응답 페이지는 모달로 확인한다.

외부 탭의 사용자 클릭이 기존 팬/청취자 내부 탭 핸들러를 호출한다. 초기 자동화 탭은 조회하지 않는다. 실제 청취자 변경을 푸시라고 주장하지 않는다. 조회 실패/새 방송에서는 전체 목록 모달에 과거 결과를 현재 결과로 표시하지 않는다.

## 스크롤·접근성

오른쪽 및 탭 콘텐츠는 natural height, overflow visible이며 고정 max-height로 자르지 않는다. 기본 목록은 짧게 제한하고 긴 설정/기록/목록은 모달로 옮긴다. 기본 오른쪽에는 스크롤 컨테이너를 만들지 않는다. 모달만 max-height 85dvh·스크롤을 사용한다. native dialog의 Escape/닫기, aria-labelledby, opener aria-expanded/controls 및 닫힌 뒤 포커스 복귀를 제공한다.

중앙 채팅 목록만 독립 스크롤을 유지하고 입력·동의/안내는 자연 흐름이다. 좁거나 확대된 화면은 페이지 스크롤을 허용한다. 기존 모바일 메뉴/한 열 배치·최소 터치 버튼·줄바꿈을 유지한다.

## 초기화·보안·보존

studio.js가 서버 모드 표시와 경로 확인 후 DOMContentLoaded에 한 번만 배치한다. simulator/automation 경쟁 배치 차단, 방송 전용 도구 주입, 다른 페이지 안전 배너 정책을 유지한다. API/SQL/후원/채팅 계약과 OAuth/SSE/Host/Origin/CSRF/CSP를 변경하지 않는다. 영구 설정·시작 context·전체 중지·가상 시간/시나리오 A–D를 유지한다. 실제 SPOON 호출·운영 DB·커밋/push 작업을 하지 않는다.

‘닫기’는 새 상세 모달의 명시적 닫기 버튼으로만 앱에서 생성하며 닫힌 모달은 기본 화면에 보이지 않는다. 이전 스크린샷의 작은 외부 버튼 출처는 여전히 미확인이다. 그것을 숨기는 CSS는 추가하지 않는다.

## 변경과 검증

studio.js/css, index.html, automation.js, audience.js, Node 레이아웃/스위치 테스트 및 Python 테스트, 본 문서.

Node에서 세 탭·기본 선택·ARIA/키보드·데이터 노드 보존·즉시 스위치 저장/실패 롤백과 기존 초기화/격리를 검증한다. Python 전체 회귀, Node 전체 연계, JS 문법, pip check, git diff --check를 실행한다.

Chrome 실제 viewport·scrollbar·bounding rectangle·125/150% 확대·모바일 가로 overflow는 미검증이다. 설치된 브라우저 도구가 없어 코드/DOM 검증을 실화면 검증으로 주장하지 않는다. 수동으로 1920×1080,1666×895,1366×768,1280×720,1024×768,390×844에서 확인한다.

`.venv/bin/python -m spoon_local --simulator` → `http://localhost:8000/broadcast`에서 자동화 스위치/저장/방송별 확인·중지, 랭킹/청취자 명시적 조회·모달·키보드·입력을 확인한다. 실제 로그인/방송/API 요청은 실행하지 않는다.
